Building this simple BreakOut game followed by nice MDN instructions, the game is dead-simple but somehow helped me to understand some canvas basics and simple UI interactions.

The game features:
- Canvas-based rendering
- Simple physics for ball movement
- Paddle control
- Brick collision detection

It was a great introduction to game development concepts using vanilla JavaScript.
