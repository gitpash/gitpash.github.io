Now I'm working on FCC projects for claiming the Front-End Certificate and figured out that almost all of them (projects) just 'copy-paste' version of provided for reverse engineering ones.

I wouldn't blame anyone, just think to myself how to implement actual 'code-standards' for my projects. So the task is clear - just build a Wikipedia viewer which will show articles and link you to the source.

I've decided to implement this using React and [Axios](https://github.com/mzabriskie/axios) (with fetch, promises and Blackjack) for AJAX request (not bearded-jQuery-stuff).

[Watch in action](https://wikipsearch.herokuapp.com)

Source code could be found [here](https://github.com/gitpash/Front-End-Dev-for-FCC/tree/master/Intermediate_Front-End/wiki-view)
